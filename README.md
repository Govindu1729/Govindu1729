## 🫀 about

I'm **Srimaan** — an indie developer at **IIT Gandhinagar** building self-hosted LLM infrastructure, agentic runtimes, and the occasional weird web thing.

I like systems that stay up, agents that don't hallucinate their way into production, and open source that ships. I fork, patch, and upstream — because the best way to learn a codebase is to break it responsibly.

> **Philosophy:** sometimes it works. when it doesn't, I read the source. this profile is a work in progress — much like every other indie project.

## ⭐ highlights

- 🚀 **Deployed 27B models with tensor parallelism on dual L40S GPUs** — air-gapped, production-adjacent inference infrastructure running self-hosted Qwen.
- 🧩 **Built an MCP-native browser extension** with ScreenCaptureKit integration — uncommon tooling, shipped end-to-end.
- 🎓 **Shipped live campus platforms serving IITGN students** — event scheduling, RBAC, and academic tracking used in production.
- 🇮🇳 **Created IndicBench** — one of the first open-source Indian-language LLM evaluation benchmarks with leaderboards.
- 🔧 **Contributed upstream to FastAPI, Transformers, Textual, Requests, and Rich** — patches merged into widely-used open-source libraries.
